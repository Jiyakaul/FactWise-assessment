Problem Statement & Operational Context

A specialized quarantine and treatment facility managing a high-consequence viral outbreak (15% mortality rate benchmark, 74-bed capacity at full occupancy) is suffering from critical operational bottlenecks:

  • Unsynchronized Rounds: Doctors visit patients before nurses take temperatures, wasting clinical bandwidth.
  • Discharge Bottlenecks: Patients stay an extra 1–2 days because 3-day fever-free recoveries are not promptly communicated to administration.
  • Zero Telemetry: No visibility into treatment efficacy or monitoring against the 15% mortality / 85% cure benchmark.

Q3: Logical Constraints & Technical Rules for Developers

In addition to UI screen designs, developers must enforce the following clinical and architectural constraints:

1. Sequential Rounding Dependency (Nurse-First Rule)

  • Daily patient vitals flags (todayTempRecorded and todayDoctorVisited) reset to false at 00:00:00 daily.
  • If an Attending Doctor opens a patient record marked Pending Vitals, the system displays an amber warning: "Warning: Temperature has not been recorded today by a nurse." The doctor is given the option to record the temperature directly, which tags the record as recordedBy: "doctor" and clears the nurse queue item.

2. The Strict 3-Day Fever-Free Cure Algorithm

  • Fever Definition: Any reading $T \ge 100.4^\circ\text{F}$ ($38.0^\circ\text{C}$) constitutes a fever.
  • Streak Reset: If on Day 3 a patient logs $100.4^\circ\text{F}$ or higher, the fever-free counter strictly resets to Day 0.
  • Discharge Permission Gate: The "Sign Discharge Order" action is disabled in the API and UI unless consecutiveFeverFreeDays ≥ 3.
  • Two-Stage Handoff: Doctor approval sets status to doctor_approved_discharge (alerting Admin desk). Only Admin completion sets status to discharged and frees the bed in the 74-bed matrix.

3. Capacity & Calculation Formulas

  • Capacity Ceiling: Hard ceiling at 74 concurrent active patients. Attempts to admit when active census = 74 returns HTTP 422 with a descriptive error.
  • Closed Cases Formula: To avoid distorting rates with active inpatients, mortality and cure rates are calculated exclusively on resolved cases: $$\text{Mortality Rate} = \frac{\text{Total Deceased}}{\text{Discharged Cured} + \text{Deceased}} \times 100, \quad \text{Cure Rate} = \frac{\text{Discharged Cured}}{\text{Discharged Cured} + \text{Deceased}} \times 100$$
  • Threshold Alert: If Mortality Rate > 15.0%, trigger high-priority alert banner across all administrative views.
